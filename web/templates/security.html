About Security Scanning

ImageGuard uses Trivy for comprehensive security scanning of container images. All images are automatically scanned for vulnerabilities before being pushed to the registry.

Severity Levels:

Severity Description Action Required
Critical Exploitable vulnerabilities that can lead to system compromise Immediate remediation required
High Serious vulnerabilities that should be addressed Remediation recommended
Medium Moderate vulnerabilities with limited impact Monitor and plan remediation
Low Minor vulnerabilities with minimal impact Informational, no immediate action needed
Policy: Images with Critical or High severity vulnerabilities are not pushed to the registry by default. You can configure thresholds in the security module settings.
