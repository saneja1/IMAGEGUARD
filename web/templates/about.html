Complete guide to the ImageGuard container security platform

🎯 Project Overview

ImageGuard is a comprehensive container image security and management platform that enables organizations to build, scan, and certify Docker container images. It provides a complete workflow from base OS images through security scanning to certified image deployment in production registries.

🔒 Security First

Real-time vulnerability scanning with Trivy integration

🏗️ Image Builder

Automated Dockerfile generation and image building

📦 Registry Management

Multi-registry support with base and certified hubs

🏛️ Architecture

Registry Infrastructure

  • Base OS Registry (localhost:5050) - Stores foundation OS images (Alpine, Ubuntu, RedHat UBI)
  • Certified Registry (localhost:5051) - Stores security-scanned and approved images
  • Docker Engine - Local Docker daemon for image building and management

Technology Stack

Backend: Flask (Python 3.x)

Security Scanner: Trivy v0.68.2

Containerization: Docker Engine

Frontend: HTML5, CSS3, JavaScript

Registries: Docker Registry 2.0

API: RESTful JSON endpoints

📄 Pages & Features

HOME Dashboard

The main landing page displaying certified, production-ready container images from the certified registry (localhost:5051).

Features:

  • Image Cards - Visual display of security-scanned, certified images with tags and metadata
  • Smart Tags - Auto-detection of image types (Ubuntu, Alpine, RedHat, Nessus, Oracle, etc.)
  • Color-coded Badges - Instant visual identification of OS platforms
  • Pull Commands - One-click copy of docker pull commands
  • Tag Listing - View all available versions/tags for each image
  • Search & Filter - Quickly find images by name or type

BUILD Image Builder

Interactive image building interface with automated Dockerfile generation and security scanning.

Build Configuration:

  • Base OS Selection - Choose from Alpine, Ubuntu, RedHat UBI, or vendor images (Nessus, etc.)
  • Runtime Selection (Optional) - Add Python, Java, or Node.js runtimes
  • Component Selection - Add monitoring agents (Prometheus, Puppet)
  • Custom Naming - Define image name and tag for easy identification
🔥 Build Process Flow:
  1. Generate Dockerfile with selected components
  2. Build Docker image using local Docker daemon
  3. Run Trivy security scan automatically
  4. Save scan results as image labels
  5. Display results in Build History table

Build History Table:

  • Image Details - Name, tag, base OS, runtime
  • Build Status - Success or failure indicator
  • Security Status - Color-coded severity badges (Critical, High, Medium, Low, Passed)
  • Security Scan Details - Click to view detailed CVE report
  • Dockerfile View - Review generated Dockerfile
  • Timestamp - Build creation date and time

CUSTOM Custom Image Build

Advanced interface for downloading external images and building custom configurations.

Features:

  • Docker Hub Download - Pull images directly from Docker Hub
  • Batch Processing - Download multiple images simultaneously
  • Progress Tracking - Real-time download status updates
  • Custom Configurations - Advanced build options for power users

SECURITY Security Scanning

Comprehensive vulnerability scanning and reporting using Trivy security scanner.

Scan Capabilities:

  • OS Package Scanning - Detects vulnerabilities in base OS packages
  • Application Dependency Scanning - Scans language-specific dependencies
  • CVE Database - Up-to-date vulnerability information from multiple sources
  • Severity Classification - CRITICAL, HIGH, MEDIUM, LOW ratings

Scan Report Details:

  • Vulnerability Summary - Count by severity level
  • CVE Identifiers - Specific vulnerability IDs
  • Affected Packages - Package name and installed version
  • Fix Availability - Shows which version fixes the vulnerability
  • Scrollable Table - Easy navigation through large vulnerability lists

🔌 API Endpoints

GET /api/images - List all images from registries

GET /api/build-history - Get build history with metadata

POST /api/build - Trigger new image build

GET /api/security-scan/<image> - Get scan details

GET /api/dockerfile/<image> - Retrieve Dockerfile

POST /api/download-images - Download from Docker Hub

POST /api/push-certified - Push to certified registry
